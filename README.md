# 🎯 Counter-Spline

### A mathematical battle where curves become weapons.

**Counter-Spline** is a turn-based shooting game developed in Python that combines programming and numerical mathematics into an interactive experience.

In the game, players use points on the Cartesian plane to construct trajectories through numerical interpolation methods and turn them into paths for their projectiles. Mathematical accuracy becomes a strategic tool to attack and defeat opponents.

## 🧮 What does the project cover?

The project brings together four main areas:

- **Numerical Mathematics:** interpolation methods and curve construction.
- **Analytic Geometry:** representation of points and trajectories on the Cartesian plane.
- **Python Programming:** development of the game's logic and mechanics.
- **Graphical User Interface:** visualization of functions, data, and game elements.

## 🛠️ Technologies

- Python
- PySide6
- NumPy
- Matplotlib
